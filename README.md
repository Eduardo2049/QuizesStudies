# Quiz com Python 

Quiz com respostas ocultas até o envio final. Padrão Spring Pattern com Middleware.

---

## 🚀 Executar Rápido

```powershell
python quiz_api.py
```

Abra http://localhost:8000

## 🔄 Formato do Quiz

O arquivo Markdown deve seguir este padrão:

```markdown
**1.** Pergunta aqui?
a) Opção A
b) Opção B
c) Opção C
d) Opção D

**2.** Próxima pergunta?
...

# Gabarito
1. c) → Explicação aqui
2. a) → Explicação aqui
```
